# Shutter-timing test data

Fixtures for `lsst.ip.isr.shutterTiming`, generated by `stackport/make_fixtures.py` in
github.com/mjuric/shutter-timing (header-card path of `shutter_timing`; see the
`generator` field of each JSON). Read-only: regenerate rather than edit.

- `MC_O_<obs>.json`, one per exposure:
  - `metadata`: the primary-header cards the helper reads (all `SHUTTER*` cards, `MJD-BEG`,
    `MJD-END`, `EXPTIME`, `SHUTTIME`, ...), keys without `HIERARCH`.
  - `detectors`: the expected per-detector results for the 189 science detectors
    (`axis`, `center_mjd_tai`, `coefficients_s` = c_u, c_uu, c_v, c_uv, c_vv,
    `max_abs_residual_s`, `effective_exposure_time_s`, `qc_flags`).
  - `visit_mjd_tai`: the focal-plane-centre time; `header_mid_mjd_tai`; `policy`;
    `exposure_qc_flags`.
  - `samples`: `[detector, x, y, t_mid_mjd_tai or null, status]` at 8 positions per
    detector (centre, 4 pixel-edge corners, one interior point, 50 px off the detector,
    and 150 px off); status 0 OK, 1 DEGRADED, 2 UNAVAILABLE.
  - `constants`: the `shutter_timing` constants the values were computed with.
  - `MC_O_20250810_000030.json` has no shutter cards: the expected result is
    UNAVAILABLE (NO_PROFILE).
- `beam_at_L3S1_z9.618_rot0_evaluated.tnt`: the shutter-plane beam table (raytrace,
  LCA-20578; A. Rasmussen). It is also public in lsst-dm/ap_pipe-notebooks
  (tickets/DM-50985).
- `lsstcam_detector_geometry.csv`: LSSTCam detector geometry exported from obs_lsst
  w_2026_10 (PIXELS -> FOCAL_PLANE, affine per detector), so ip_isr tests need not
  import obs_lsst.

Agreement target: centre times and quadratic terms at a 2000-pixel lever arm to
<= 10 us; identical `axis`, flags and statuses.
